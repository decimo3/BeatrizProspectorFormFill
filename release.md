# Initial release

This release improves form-filling reliability and performance across supported sites.
It adds more robust Excel data extraction and error handling to reduce crashes.
Multi-language support (including Portuguese refinements) has been expanded.
Chromedriver and browser-automation components were updated for better compatibility.
Logging, temporary-file cleanup, and minor bug fixes improve stability and diagnostics.
Overall, this release focuses on reliability, compatibility, and maintainability.
